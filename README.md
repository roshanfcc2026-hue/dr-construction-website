# D & R Construction LLC

A responsive portfolio website for D & R Construction LLC in Wauseon, Ohio.

## View the website

[Open the live website](https://roshanfcc2026-hue.github.io/dr-construction-website/).

Download this repository using **Code > Download ZIP**, extract it, and open `index.html` in your browser. No installation or build step is required.

## Included

- Complete HTML, CSS, and JavaScript website
- Project photographs and category galleries
- Responsive layouts and keyboard-accessible controls
- Estimate request form with a visitor email field

## Estimate requests

The form opens an email draft addressed to Cantu.sass89@icloud.com. The visitor must send the draft using their email app. This website does not store submissions or send them automatically.

## Editing

- `index.html`: page content and sections
- `project-data.js`: project information and photo selections
- `projects.js`: gallery navigation
- CSS files: page styling
- `assets/`: photographs and other website assets

Keep the folder structure intact when sharing or hosting. Original business photography and branding remain subject to their respective owners' rights; this repository does not grant a reuse license.
